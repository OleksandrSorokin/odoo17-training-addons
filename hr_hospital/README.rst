Hospital
========

Odoo 17 training module. Supports doctors, interns, mentors, patients,
visits, diagnoses, diseases, analytical views, and a report wizard.

The module 4 demo importer is intended for training databases only.
After importing it in an Odoo shell, call ``load_demo(env)`` explicitly.
It is idempotent for entries registered by the importer's XML IDs.
