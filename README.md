Odoo 17 training addons

## Development environment

Training environment for Odoo 17 development.

- Odoo: 17.0
- Ubuntu: 22.04 LTS / WSL2
- PostgreSQL: 14
- Project 1 HTTP port: 15069
- Project 2 HTTP port: 15070
- OCA/web 17.0 is used for third-party addons
